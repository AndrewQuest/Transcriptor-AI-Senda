# Senda 0.2.1 — Windows preview

- La cápsula aparece abajo en el monitor de la aplicación activa al iniciar el dictado. Mantiene ese monitor durante la sesión y se recoloca si cambia la disposición de pantallas. Conserva sombra, transparencia y animaciones sin activar la ventana.
- Nueva opción «Pulsar Enter automáticamente después de pegar», inicialmente desactivada también al actualizar. Su explicación permanece visible y está traducida al inglés. Activarla puede enviar mensajes, confirmar acciones o ejecutar comandos según la aplicación.
- El modo se captura al empezar cada dictado. Enter se intenta una sola vez después del pegado; se comprueban destino, campo con foco, modificadores y cancelación. Esc puede cancelar un Enter pendiente. No se aplica al copiar ni al corregir.
- Tras intentar Enter, la corrección del texto enviado requiere copiarla manualmente. Los registros de entrada indican eventos despachados, no una confirmación de recepción de la aplicación externa.

Se conservan modelos, historial y ajustes. Cierra Senda desde la bandeja antes de instalar. El instalador y el ZIP incluyen los componentes necesarios para Windows 11 x64 y todavía no tienen firma de editor.

## English

The dictation capsule now uses the target app's monitor. An optional, initially disabled setting presses Enter after pasting, with a permanent explanation of its effects. Focus changes and cancellation skip automatic Enter; no automatic retries are performed. Input dispatch does not acknowledge message submission by the receiving app. Exit Senda from its tray icon before updating. This is an unsigned Windows 11 x64 preview.
