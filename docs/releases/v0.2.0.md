# Senda 0.2.0 — Windows preview

## Descarga e instalación

- **Instalador:** `Senda-Setup-0.2.0-win-x64.exe`. Instala para el usuario actual, sin permisos de administrador.
- **Portable:** `Senda-0.2.0-Windows-x64.zip`. Descomprime toda la carpeta y abre `Senda.exe`.
- `SHA256SUMS.txt` permite verificar los archivos y `build-info.json` identifica versión, commit y SDK.

Cierra Senda desde la bandeja antes de instalar o actualizar. El instalador ofrece español e inglés. La aplicación conserva modelo, ajustes e historial en `%LOCALAPPDATA%\Senda`; la desinstalación conserva esos datos. Descarga Base o Small desde Ajustes en la primera ejecución. Los pesos no se incluyen en el instalador.

## Novedades

- Instalador y ZIP para Windows x64 con los componentes necesarios incluidos.
- Modo oscuro, claro y del sistema; cristal opcional y cápsula de dictado con bordes difuminados y transiciones breves.
- Atajos personalizados, conservando Ctrl + Alt + Espacio y Ctrl + Mayús + Espacio.
- Interfaz seleccionable en español o inglés, independiente del idioma del dictado.
- GPU Vulkan opcional, con CPU predeterminada y alternativa sin AVX.
- Base y Small multilingües cuantizados mediante descarga verificada con SHA-256.
- Tiempos del último dictado y ayuda de puntuación experimental optativa.
- Captura en RAM, historial local cifrado y corrección con comprobación del texto de destino.

## Requisitos y límites

Windows 11 x64. Las bibliotecas nativas fijadas de Whisper.net requieren Windows 11 o Windows Server 2022; Windows 10 no se considera compatible para esta distribución. Microsoft Visual C++ Redistributable x64 para Visual Studio 2022 puede ser necesario para el motor nativo. CPU funciona sin GPU; Vulkan requiere un controlador compatible.

Versión de prueba. El instalador y el ejecutable todavía no tienen firma de editor, por lo que Windows puede mostrar avisos. No incluye reescritura con LLM ni streaming. La puntuación es generada por el modelo y puede requerir correcciones. La guía experimental solo se aplica con español o inglés fijo.

## English

Download the EXE installer or extract the entire portable ZIP and open `Senda.exe`. Exit Senda from the system tray before installing or updating. In Settings, choose English as the interface language and save. Download a speech model once; dictation then works offline. Windows 11 x64 and the Visual C++ x64 runtime are required by the selected native engine. GPU acceleration is optional. This is an unsigned preview release. Uninstalling keeps personal settings, models and encrypted history.
